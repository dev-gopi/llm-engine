# Security Policy

## Supported versions

Security fixes are applied to the current default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Use GitHub's private vulnerability-reporting feature for this repository when
available. If it is unavailable, contact a repository maintainer privately via
their GitHub profile with a description, reproduction steps, affected versions,
and any suggested mitigation.

We will acknowledge reports, investigate them, and coordinate disclosure before
publishing a fix where practical.
